2019：指数修复，白酒与科技双主线，东方通信带起妖股行情

阶段总览 · 上一阶段：2018 · 下一阶段：2020

2019 年是 2018 年大跌后的修复年。指数明显上涨，机构买白酒和科技龙头，游资炒 5G、工业大麻、氢能源、股权转让和网红经济。 不同资金都能找到机会，但它们赚的钱不是同一种钱：茅台主要赚盈利与估值提升的钱，万集科技赚 ETC 政策落地后的业绩爆发，东方通信则主要赚题材和接力情绪的钱。

所以，“2019 年涨了很多”不等于全年一路上涨。春季追高后持有与年初低位布局，实际体验可能很不一样。

相对落后方向主要包括钢铁、建筑装饰、部分传统公用事业等。这里说的是涨幅落后于科技和消费，并不是这些行业全年全部下跌。传统投资需求缺少足够强的上修，部分低估值资产有分红，却没有同样鲜明的增长催化。

真正跌得明显的个股，还包括财务造假、债务或退市风险暴露的公司。康美药业的财务问题、康得新的信用与财务问题，与“整个医药或材料行业看空”是两件事。2019 年不能只按行业买，还需要排除公司自身的雷。

三、哪些股成为妖股：把年度牛股与短线妖股分开看

“妖股”是市场俗称，指短期连续涨停、波动和情绪显著强于普通股票的标的，不是官方分类；下面选的是代表案例，不冒充统一的年度排名。

股票 主要活跃期 市场当时炒什么 最需要分清的一点
东方通信 2018 年末至 2019 年春季 5G、通信主题、龙头接力 名字和行业联想很强，不等于公司已经获得与涨幅相匹配的 5G 利润。
顺灏股份 春季 工业大麻 政策和业务想象先于成熟利润，不能按传统烟草消费股理解。
美锦能源 春季 氢能源、燃料电池 市场重估新业务空间，不能只靠传统焦化利润解释股价。
金力永磁 5—6 月 稀土、贸易摩擦下的战略资源 交易的是事件与资源议价预期，不只是当季报表。
九鼎新材、宝鼎科技 下半年 控制权变化、股权转让与资产注入想象 换股东提供想象，但资产注入与利润兑现仍有条件。
漫步者 四季度 TWS 无线耳机 真实产品趋势与短期情绪同时存在。
星期六 12 月启动，延续至 2020 年初 遥望网络、网红经济、直播电商 鞋业公司被按新业务重新讲故事，不能把跨年涨幅全算在 2019 年。

另一个必须记住的名字是 万集科技。它是年度大牛股，但与单纯接力型妖股不同：ETC 政策直接推动产品出货和业绩。公司年报也提醒，集中安装完成后，后续需求不能继续按同一速度外推。

案例出处：年度牛股与题材盘点、万集科技 2019 年报。表中“炒什么”描述当时的市场叙事，不代表相关承诺或传闻最终都兑现。

四、不同博弈主题，究竟赚的是什么钱

1. 核心资产：从“怕踩雷”到“愿意为确定性加价”

2018 年信用收缩和民企风险，让不少机构不愿继续押注需要反复融资的小公司。白酒等龙头经营现金流较好，外资和公募更容易建立长期盈利判断。资金集中买入后，股价不只跟随利润增长，市盈率也上升。

这条线的顺序是：担忧不确定性 → 选择盈利较稳的龙头 → 资金持续配置 → 盈利增长与估值提高共同推升股价。 它与游资连板的机制不同，但同样可能在价格过高后变得拥挤。

2. 国产替代：外部限制把“可选项”变成“必须考虑”

华为等事件使供应链安全受到重视。客户更有动力测试国内芯片、设备和材料，市场因此提高国产供应商的未来收入预期。这里有真实产业逻辑，但需要经过认证、量产、采购和回款，才成为公司利润。

所以，科技股内部要区分两类：已有产品与客户、可能获得真实份额的企业；主要依靠名字、概念或远期规划吸引交易的企业。同属国产替代题材，估值依据并不相同。

3. ETC 与猪周期：政策或供给改变，直接落到盈利

ETC 是集中安装拉动订单；猪周期是供给收缩推高猪价。两者都有可跟踪的经营指标，比纯概念更接近利润，但也有周期终点：安装任务不能每年重做，猪价上涨又会刺激补栏和扩产。

4. 工业大麻、股权转让、网红：先抢最有辨识度的交易标的

这些行情中，资金常先选出一个最容易被市场记住的龙头，再通过涨停和成交吸引跟随者。参与者更关心新催化、连板高度和下一批买方。短期股价的核心不一定是当年利润，而是叙事能否继续传播、资金能否继续接力。

这解释了为什么同一个月茅台和妖股都可能涨：一个靠机构持续配置，一个靠情绪扩散。把它们都归结为“流动性好”，就丢失了投资者最需要知道的差别。

六、站在投资者角度：修复、盈利与题材接力怎样区分

2019 年既有总量修复，也有选股标准变化。春季反弹能用悲观预期修复解释；持续到下半年的白酒、半导体和消费电子，则必须用各自的经营与资金逻辑解释。

对投资者，最有用的复盘是分清四种上涨：便宜资产恢复正常估值，龙头利润持续增长，新产业获得真实订单，以及题材资金推高价格。 它们可以同时发生，却需要不同的退出与验证条件。

2018 年教会市场怕信用风险，2019 年把资金推向“核心资产”和“科技自主”，2020 年基金扩张又会放大这两种偏好。这才是三个年份之间的联系，而不是每年重新换一个热门概念。
