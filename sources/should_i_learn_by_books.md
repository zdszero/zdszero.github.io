% 读书学习投资有用么

### 传播的信息 ≠ 真相

投资知识的传播方式，与真正形成投资能力的方式，存在很大的错位。

比如我们从 2005 年股改开始，连续追问：

- 为什么会有非流通股？它们由谁持有？
- 为什么非流通股存在巨大的折价？
- 10 送 3.5 究竟是谁向谁转移利益？
- 为什么要停牌、谈判、投票？各方的博弈能力有什么差异？
- 股改为什么会改变估值？又为什么恰好引发了 2005–2007 年的大牛市？

这些问题连起来，实际上是在重建一个市场运行机制，而不是背诵历史结论，但是书籍却很少这样讲。

### 为什么书籍和自媒体很少这样讲？

我认为有三个原因。

**第一，真正有价值的知识往往是非标准化的。**

一本投资书可以告诉你：

> 买入优秀企业，长期持有，保持安全边际。

这没有错，但对于一个具体问题，例如「2005 年非流通股股东为什么愿意支付 3.5 股的对价」，帮助非常有限。

要回答它，必须同时理解公司法、股权结构、市场流动性、利益分配和博弈机制。

这些知识散落在不同领域，没人替你组织好。

**第二，市场上容易传播的是结论，而不是推导过程。**

「2005 年股改催生超级牛市」非常适合做一个五分钟视频。

但要讲清楚股改为什么影响股价，可能需要研究几十家公司的改革方案、当年的股东结构、停复牌制度、基金持仓和估值变化。

研究成本高，传播效果未必好。

**第三，投资是一门强反馈噪声的学科。**

这是它和你熟悉的计算机工程非常不同的地方。

工程中，优化一个 kernel，benchmark 可以告诉你延迟是否下降。

投资中，即使你的判断逻辑正确，股价也可能连续两年不涨；即使判断完全错误，也可能因为流动性而赚三倍。

因此，市场很难及时奖励正确的研究方法，反而经常奖励错误的自信。

### 书籍的用处

我会做一个区分：

书籍适合建立基本理论，历史研究适合理解市场机制，真实投资则负责检验你的判断。

例如：

| 学习方式    | 能获得什么         | 难以获得什么      |
| ------- | ------------- | ----------- |
| 投资经典书籍  | 估值、复利、风险、心理偏差 | 中国市场具体的制度博弈 |
| 金融史、市场史 | 泡沫、危机、流动性周期   | 当时投资者究竟如何决策 |
| 原始资料研究  | 政策、股权结构、资金行为  | 对未来的确定性预测   |
| 真实投资与复盘 | 风险承受能力、决策反馈   | 排除运气后的真实能力  |

我甚至觉得，你现在最应该培养的不是「选股技巧」，而是从历史事件中提取可迁移机制的能力。

例如研究股改，最终不应该只记住「2005 年股改带来了牛市」，而应该提取出：

某种制度性约束消失 → 资产的潜在买家群体扩大或风险溢价下降 → 估值体系改变 → 边际资金进入 → 价格上涨 → 可能出现正反馈泡沫。

然后再问：未来二十年，哪些市场或资产可能发生类似的变化？

这比记住 6124 点有用得多。

不过，还有一个值得警惕的陷阱：历史解释能力不等于事前预测能力。

我们今天很容易把股改、人民币升值、外汇占款、盈利增长串成一条漂亮的因果链。但站在 2005 年，你能否区分「合理的制度性重估」与「已经被充分定价的利好」？能否识别当时尚未发生的资金流入？能否判断哪些公司真正受益？

这才是研究的难点。

我建议你以后研究每一轮 A 股行情，都强制自己回答两个问题：

1. 如果我站在行情开始之前，当时有哪些公开信息足以支持买入？
2. 如果我判断错了，什么事实能够证明我的投资逻辑已经失效？

第一个问题训练发现机会的能力，第二个问题防止把任何历史故事都解释成自己正确。

你现在这种「野蛮生长」式的学习，最值得保留的是不断追问机制，而不是满足于一个听起来合理的叙事。

真正稀缺的不是知道某一轮牛市为什么发生，而是在下一轮牛市发生之前，识别出那些尚未被市场充分定价的变化。


### 关于炒股养家

中国论坛过去一直流行 炒股养家 之类的文章，让散户觉得自己参透了 A 股的真谛。

但仔细阅读，会发现其中都是泛泛的叙述，不包含具体的细节，是无法证伪的理论。

一个真正可验证的交易系统，至少应该能够写成：

> 条件 A + 条件 B + 条件 C
> 
> → 买入
>
> → 止损条件 X
>
> → 止盈条件 Y
>
> → 历史样本 N 次
>
> → 胜率 53%
>
> → 盈亏比 1.8
>
> → 最大回撤 17%

所谓 “心法” 通常没有这些东西，而是更加接近 **一个成功交易者对自己行为的主观压缩描述**，而不是 一套经过统计验证的 trading system。

这里举一个具体的例子，文章中提到了很多概念，比如 【盘感】、【退潮】，比如退潮是：

- 涨停数量下降？
- 连板高度下降？
- 炸板率上升？
- 龙头跌停？
- 成交额下降？
- 高位股亏钱效应扩大？
- 还是他看盘时感觉“不对”？

如果没有定义，你根本无法回测。这些都是 **不可证伪叙事**。

所以作者本人可能是一个优秀的股票交易者，但网络上流传的“炒股养家心法”，没有足够证据证明它本身是一套 **可复制的正期望交易策略**。

所以 **优秀交易者 ≠ 优秀交易教材作者**，一个好的学者也不一定是一个好的老师。

这在各个领域都是非常常见，一个人可以非常会游泳，但让他写一本《游泳成功学》，里面可能全是：

> 保持身体平衡。
> 
> 顺势而为。
> 
> 控制呼吸。
>
> 不要逆水而行。

### 复杂系统的学习

**复杂适应系统** 的特性：

> 宏观秩序不是由一个全知的中央控制器设计出来的，而是大量局部主体在有限信息、有限资源和局部规则下不断互动，最终涌现出来的。
>
> **局部互动产生整体结果，而整体结果又反过来改变局部主体的行为。** 这才构成一个不断演化的系统。

复杂系统学习与传统应试教育最根本的区别：知识可以通过传授获得，**但对系统的判断力必须通过与系统交互形成。**

**复杂系统中最有价值的知识，往往不是关于节点的知识，而是关于节点之间如何相互影响、反馈和演化的知识。**

以 A 股为例。你可以通过读书知道：

- 什么是股权分置改革、去杠杆、流动性危机。
- 什么是 PE、EPS、风险溢价、信用收缩。
- 什么是机构、游资、量化、散户。

这些都是节点知识。应试教育非常擅长传授它们。

但真正决定投资结果的，是连接关系：

信用收缩 → 企业融资困难 → 经营预期恶化 → 股价下跌 → 股权质押风险上升 → 被动卖出 → 股价进一步下跌。

这是一条具有正反馈特征的因果链。更重要的是，**链条中的参与者会根据其他人的行为改变自己的行为。**

你即使掌握全部概念，也未必能在 2018 年的真实市场里及时识别这条链。

学习复杂系统 **有三层：**

- 第一层：学习系统的组成：掌握概念、规则、历史事实和基本机制。传统书籍、课程非常有效，但这还只是建立地图。
- 第二层：理解系统的连接：研究参与者的利益、约束、激励、相互依赖，以及反馈回路。这需要案例、数据、历史复盘和因果推导。
- 第三层：在真实反馈中校准自己的模型：做出事前预测，承担适度后果，观察偏差，修改模型，再次验证。最终形成能适应环境变化的判断力。

第三层最难，因为复杂系统有一个很麻烦的特点：**正确的决策可能产生错误的结果，错误的决策也可能产生正确的结果。**

因为人类的推导大多是因果关系，但是真实系统演变大多是 多方面共同相互影响 的叠加效果，这种演变无法用数学公式描述。

另外，在物理系统里，你学习规律，规律不会因为你学会了而改变。但在金融市场里有 **反身性**：**当足够多的人学会某个规律，规律本身就可能失效。**
